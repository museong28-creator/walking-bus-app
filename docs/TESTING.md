# 검증 결과 · v0.2

## 최종 자동 검사

- `npm run check`: 통과
- JavaScript 구문 검사: 통과 (도보·약속·공유 UI/클라이언트, Node 공유 서버, 서비스 워커)
- Node 자동 테스트: **161개 통과, 실패 0개, 건너뛴 항목 0개**
- `npm run build`: 통과, `dist/` 정적 산출물 생성

자동 테스트는 GPS·브라우저·네트워크를 모킹한 로직 검증입니다. 실제 iPhone 센서나 외부 서비스의 지속적인 가용성을 보증하지 않습니다.

### 검사 범위

- 좌표 범위·숫자 형식, 구면 거리, 경로 길이·경로 투영·남은 거리
- null GPS 속도와 0 속도의 구별, 위치 변화 기반 추정, GPS 잡음
- 부정확한 위치, 역순·중복 시각, 위치 점프, 장시간 신호 공백
- 보행 범위를 벗어난 속도, 정지 시 ETA 보류, 속도 미측정 상태
- 위치 권한 거부, 오래된/미래 시각의 위치, 중지 후 도착하는 낡은 콜백
- 페이지가 숨겨졌을 때 GPS 중지
- 화면 켜짐 유지 요청 실패 및 빠른 중지/재시작의 비동기 충돌
- 외부 서비스 HTTP 오류·잘못된 JSON·비정상 좌표·과도한 경로 스냅
- 검색 요청 간격 제한과 세션 캐시, 요청 취소
- 직접 입력 버스 시간 검증, 카운트다운, 만료, 보행 ETA 미확정 상태

### v0.2 약속·친구 공유 검사

- 목표 시각, 여유 시간, 필요한 km/h·분/km, 편한 속도 상한과 지각 상태
- 현재 속도가 없을 때 임의 ETA를 만들지 않음, 무리한 목표 속도를 UI에 권하지 않음
- 버스 수동 입력의 정확한 절대 도착 시각을 목표 시간 계산으로 연결, 1분 여유 적용
- HTTPS 서버/초대 링크 검증, URL에 개인 토큰·좌표를 넣지 않는 POST 요청
- 방 생성·초대 참여만으로는 위치를 공유하지 않음
- 표시 이름·목적지 전송 동의와 반복 위치 공유 동의의 분리, 거절 시 미전송
- 실제 두 독립 MeetingClient가 **실제 localhost HTTP 서버**로 방 생성·참가·발행·조회·중지·종료를 수행
- 초대/참가자 인증, 본인 위치만 수정, 호스트만 전체 종료, 방 만료·정원·요청 크기·CORS·요청 한도
- 공유 중지 후 늦은 발행이 위치를 다시 만들지 않음, 중지/재시작·참가 취소의 비동기 충돌
- UI는 한 번에 한 위치만 발행하며 새 GPS·표시 중인 화면에서만 전송
- 오래된 위치 30초 표시·90초 숨김, 연결이 끊겨도 지도에서 자체 만료
- DOM 이벤트 검사: 실제 공유 위치만 친구 핀에 사용, 체험 위치 미전송, 배경 전환·GPS 중지·목적지 변경 시 공유 중지
- 중지 실패 시 새 전송은 차단하고 서버 삭제가 확인되지 않았음을 표시
- 초대 링크 복사는 클립보드만 변경하며 친구에게 자동 메시지를 보내지 않음
- 외부 이름·오류·목적지의 문자열 처리, 잘못되거나 다른 방의 응답 거부

`meetup-ui.test.mjs`의 34개 검사는 DOM·Leaflet·네트워크를 대체한 실제 이벤트 처리 검사입니다. 별도의 실제 localhost 프로토콜 검사와 구분해야 합니다. 실제 친구 위치나 개인 데이터를 테스트에 사용하지 않았습니다.

## 기존 도보 UI 브라우저 검사 (v0.1)

클라우드 Chromium에서 실제 UI 조작으로 확인했습니다.

- 초기 개인정보 안내 및 온라인 지도 활성화
- 실제 OpenStreetMap 지도 타일 표시
- 네트워크 없이 동작하는 가상 보행 체험, 가상 표시, ETA 갱신
- 직접 입력 버스 시간 비교 및 실시간이 아니라는 표시
- 지도 클릭으로 출발지·목적지 선택
- 도보 경로 동의 취소 후 재요청
- 실제 보행 전용 경로 응답 및 경로선·ETA 표시: 서울의 공개된 임의 지점 사이 **약 838m, 설정 4.3km/h에서 약 12분**
- 390px 너비 모바일 iframe에서 초기 화면과 체험 화면의 반응형 레이아웃 시각 검토
- 체험 화면에서 겹치던 출발지 버튼 숨김 수정 후 재검토

추가로 고정된 공개 서울 좌표를 이용한 직접 요청에서 FOSSGIS 보행 경로 **1,032.4m** 응답을 받았습니다. 사용자 실제 위치는 테스트에 쓰지 않았습니다.

## 미검증 또는 제한

- **v0.2 추가 약속·친구 UI의 실제 브라우저 시각 검토:** 아직 하지 않았습니다. DOM 이벤트·상태·네트워크 흐름 검사는 통과했지만 레이아웃/터치 현장 검증을 대신하지 않습니다.
- **두 실제 휴대전화 간 공유:** 아직 하지 않았습니다. localhost의 실제 두 클라이언트 HTTP 통신만 검증했습니다. HTTPS API 배포 후 각자 동의한 기기로 시험해야 합니다.
- 공유 서버 공개 배포·보안 인증·부하 시험·운영 프록시/로그 검증: 하지 않았습니다. 일회성 링크 방식, RAM 단일 프로세스와 신원 미확인 한계는 `SHARING_SERVER.md`를 확인하세요.

- **실제 iPhone Safari에서 걸으며 GPS 측정:** 아직 하지 않았습니다. HTTPS 배포 후 현장 테스트가 필요합니다.
- 실제 iOS에서의 권한 팝업, 배터리·화면 잠금·저전력 모드 차이: 미검증입니다. 자동 테스트는 상태 처리만 검증합니다.
- **주변 정류장 실데이터:** Overpass 연결 코드는 구현하고 응답·오류 처리 테스트를 통과했지만, 이 실행 환경의 실제 요청은 HTTP 406 응답으로 성공 검증을 못 했습니다. 실패하면 UI에 오류를 표시하며 정류장을 만들어내지 않습니다. 배포 후 실제 환경에서 재확인이 필요합니다.
- Nominatim 장소 검색의 전체 실서비스 성공 흐름: 모킹 테스트만 완료했습니다. 좌표 입력과 지도 선택은 외부 장소 검색 없이 사용할 수 있습니다.
- **전국 실시간 버스 도착:** 구현·연결되지 않았습니다.
- GitHub 저장소 push 및 GitHub Actions 배포: 대상 저장소가 없어 실행하지 않았습니다.
- 완전한 오프라인 지도/내비게이션: 지원하지 않습니다. 앱 셸과 가상 체험만 오프라인 사용을 위한 기본 캐시를 제공합니다.

공용 API의 가용성·데이터 품질은 달라질 수 있습니다. 버스 시간 비교는 사용자가 직접 입력한 시간을 기준으로 한 추정이며 탑승을 보장하지 않습니다.
