# pace-21: 한국어 검색과 현재 위치

## 반영한 수정

- 검색창을 `type=text`, `inputmode=text`, `lang=ko`로 지정했습니다. 휴대폰 키보드 언어 자체를 웹페이지가 강제로 변경하지는 않습니다.
- 한글 입력 조합 중 Enter를 누르면 미완성 검색어가 제출되지 않게 했습니다. 조합 완료 후 검색 버튼 또는 Enter를 사용합니다.
- 지도에 `내 위치` 버튼을 추가했습니다. 신뢰할 수 있는 최신 GPS가 있으면 바로 이동합니다. 그렇지 않으면 위치 권한을 요청하고 새 위치를 한 번 확인합니다.
- 수동 출발지를 현재 GPS 위치로 표시하지 않습니다. 목적지와 진행 중 보행 속도 표본을 유지합니다.
- 위치 확인이 늦거나 부정확하면 지도 안에 이유와 다음 행동을 보여줍니다. 화면을 떠난 뒤 도착한 응답은 반영하지 않습니다.
- 모의 GPS와 검색 조합을 포함한 앱 검사 53개가 통과했습니다. 실제 iPhone 한국어 키보드와 위치 센서 확인은 별도로 필요합니다.

## TAGO 신청 준비

| 구분 | 신청 대상 |
|---|---|
| 정류소 식별 | [국토교통부 TAGO 버스정류소정보](https://www.data.go.kr/data/15098534/openapi.do) |
| 실제 도착시간 | [국토교통부 TAGO 버스도착정보](https://www.data.go.kr/data/15098530/openapi.do) |

두 API는 공식 안내상 무료입니다. 정류소정보 화면에서 개발 단계 자동승인과 10,000회 신청 한도를 확인했습니다. 실제 승인 여부는 로그인 후 각 신청 결과에서 확인해야 합니다.

활용 목적: 개인용 웹앱 몇분 걸음에서 공식 버스 정류소와 도착예정정보를 조회하여 개인 보행 속도로 계산한 정류장 도보 시간과 비교합니다. 첫 검증 대상은 대구대(정문1), 894번 부기리 방면입니다.

신청 이후 일반 인증키의 Decoding 값을 Render 기존 무료 서비스의 `TAGO_SERVICE_KEY`에 등록합니다. 키는 공개 소스, 채팅, 웹앱 입력란에 넣지 않습니다. Render의 `Save only`는 실행 서버에 즉시 반영되지 않으므로 실제 적용 배포의 성공을 확인해야 합니다.

이번 작업의 승인, 키 등록 및 실제 도착정보 성공 여부는 별도 확인이 필요합니다. 준비된 코드나 공개 웹의 정류장 이름만으로 실제 연결 완료라고 판단하지 않습니다.
