# pace-22 실제 버스 도착정보 연결

2026-11-20 TAGO 버스정류소정보와 버스도착정보 무료 개발계정을 신청했고 두 건 모두 자동 승인됐습니다. 인증키는 Render 기존 무료 서비스의 `TAGO_SERVICE_KEY`에만 등록했습니다. 기존 이미지에 환경 변수를 적용한 배포 `dep-dbvrogijnfac7387ri00`은 live입니다.

## 방면 제한

[대구시 공식 894번 노선도](https://businfo.daegu.go.kr:8095/dbms_web/map?searchText=894)에서 정방향과 역방향 모두 대구대(정문1)를 지나는 것을 확인했습니다. 정방향은 이후 부기리, 역방향은 이후 부기2리 건너와 부기리LH아파트 건너를 지납니다. TAGO 도착 응답은 같은 routeid를 사용하며 방면 필드가 없습니다.

따라서 UI는 실제 894번 도착예정 시간과 정류장까지의 실제 도보 시간을 나란히 표시하되 부기리 방면 구분과 탑승 가능 판정은 제공하지 않습니다. ‘부기리 방면 확인 필요’를 표시합니다. 특정 방면의 버스와 안전하게 연결하려면 방면이 포함된 공식 도착 데이터가 필요합니다. 대중교통 전체 경로 검색은 이 API와 별개이며 연결하지 않았습니다.

## 비용과 보호

실제 계정 화면에서 카카오맵 유료 API ‘사용 안 함’, Firebase Spark ‘무료($0/월)’, Render Hobby 및 Free 인스턴스를 확인했습니다. Render Billing에는 ‘No card on file.’과 현재 $0.00이 표시됐습니다. 결제 수단이나 유료 옵션을 추가하지 않았습니다.

- TAGO 도착정보는 버튼을 누를 때만 조회합니다. 자동 반복 조회를 하지 않습니다.
- Firebase 로그인과 기존 UID 허용 목록, 서버 호출 한도를 유지합니다.
- 키는 클라이언트나 정적 배포에 포함하지 않습니다.
- 조회 후 30초가 지나면 도착시간을 숨깁니다. 로그아웃과 화면 전환 시 응답을 폐기합니다.
- 다른 목적지, 체험 경로, 경로 실패, GPS 부정확 상태의 도보 시간을 이 정류장 시간으로 쓰지 않습니다.
- 버스 조회는 위치를 서버에 보내지 않고 고정 정류소 식별자만 보냅니다. 도보 경로는 기존 전송 동의를 거칩니다.

## 검증 범위

버스 비교, 취소, 만료, 로그아웃, 한도 오류를 포함한 관련 검사 70개가 통과했습니다. 한글 검색과 현재 위치 버튼은 pace-21에서 이미 공개 배포했습니다. 실제 iPhone 야외 보행, 한국어 키보드 조합, 화면 잠금 복귀, 정류장 행선판 대조는 사용자 기기 확인이 필요합니다.

공개 pace-22에서 기존 Google 계정 로그인 후 Render를 통한 TAGO 실제 도착 조회도 성공했습니다. 오전/오후 표시는 사용자 기기의 한국 시간 설정을 따릅니다. 보행로 끝점과 선택한 출발지가 20m 넘게 떨어진 경우에는 실제 경로를 받아도 예상 시간을 숨기는 것을 확인했습니다.

지도에서 고른 공개 지점에서 정류장까지 FOSSGIS 실제 도보 경로 73m, 기본 속도 4.3km/h 기준 약 2분과 실제 버스 도착정보가 동시에 표시됐습니다. 이는 실제 사용자의 위치나 측정 속도가 아닙니다.
