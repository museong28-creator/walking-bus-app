# 개인정보 및 외부 서비스 안내

## 브라우저 안에서 하는 일

- GPS 좌표·시각·오차·속도를 이용해 보행 속도와 남은 거리를 계산합니다.
- 기본 모드의 위치 데이터는 현재 페이지의 메모리에만 유지합니다. **친구 공유를 명시적으로 켜면 아래와 같이 마지막 위치를 서버와 참가자에게 공유합니다.** 분석 서비스나 이동 이력 저장소로 보내지 않습니다.
- 위치 권한은 “내 위치로 걷기 시작”을 누른 뒤 브라우저에서 요청합니다.
- GPS를 멈추거나 페이지가 숨겨지면 위치 감시를 해제합니다. 마지막 측정 지점은 현재 페이지에 남을 수 있으며 새로고침하면 사라집니다.
- 서비스 워커는 정적 HTML/CSS/JavaScript 등 앱 셸만 캐시합니다. 위치가 포함된 경로·검색·정류장 API 요청과 지도 타일은 이 앱이 오프라인 캐시에 저장하지 않습니다. 브라우저와 각 외부 서비스의 정상적인 HTTP 캐시·로그는 별개입니다.
- 계정, 쿠키 기반 추적, 분석 SDK, 광고 SDK, 비밀 API 키가 없습니다.

## 외부에 전달되는 정보

1. **페이지 호스팅 제공자:** 웹사이트 접속 자체의 IP·일반적인 요청 정보. GitHub Pages 등 배포자가 정한 호스팅 정책이 적용됩니다.
2. **OpenStreetMap 지도 타일** (`tile.openstreetmap.org`): 온라인 지도를 켠 경우 표시 영역에 해당하는 타일 좌표와 IP. 지도를 현재 위치로 이동하면 그 주변 지역이 드러날 수 있습니다. 정확한 GPS 위치를 별도 파라미터로 보내지는 않지만 확대된 타일 영역으로 대략적인 위치를 유추할 수 있습니다.
3. **Nominatim** (`nominatim.openstreetmap.org`): 동의한 장소 검색어와 IP. 주소를 입력하면 그 주소가 검색 서버로 전달됩니다. GPS 좌표를 자동 첨부하지 않습니다.
4. **FOSSGIS 도보 라우팅** (`routing.openstreetmap.de`): 동의한 출발지·목적지 정확 좌표와 IP. 버튼을 눌러 요청할 때만 전송하며 GPS 업데이트마다 재전송하지 않습니다.
5. **Overpass** (`overpass-api.de`): 주변 정류장 검색에 동의한 기준 위치의 정확 좌표, 반경 700m와 IP.
6. **직접 설정한 약속 공유 서버와 방 참가자:** 방 생성·참가 시 동의한 표시 이름, 목적지 이름·좌표, 약속 시간. 별도의 위치 공유 시작 동의 후에는 정확한 현재 좌표, 측정 시각·오차, 보행 속도, 확인 가능한 경우 도보 ETA. 화면을 켠 동안 새 GPS 값을 최대 약 5초 간격으로 전송합니다.

검색어·경로 좌표는 해당 서버가 처리하는 URL에 포함됩니다. 운영자가 로그를 남길 수 있고 데이터 처리 정책이 서로 다릅니다. 이 앱의 동의 창이 각 서비스 이용약관을 대신하지 않습니다.

온라인 지도 끄기는 새로운 타일 요청을 중단합니다. 이미 전송된 정보나 서버 로그를 삭제하지는 않습니다. 장소·경로·정류장 검색 동의는 해당 요청 한 번에 적용됩니다. 친구 공유의 반복 전송은 별도 안내와 공유 시작 동의를 거칩니다.

## 친구 위치 공유

- 초대 링크를 열거나 방에 참여하는 것만으로 현재 위치를 보내지 않습니다. “공유 시작”에서 **반복 전송**의 항목·서버·받는 사람·종료 방법을 확인하고 동의해야 합니다.
- 초대 링크는 접근 권한입니다. 링크를 받은 사람이 추가로 참가할 수 있으며 표시 이름은 본인 인증이 아닙니다. 안전한 상대에게만 직접 보내 주세요.
- 초대 토큰은 URL의 `#` 뒤에 있으며 일반 HTTP 요청에는 포함되지 않습니다. 참여 후 주소창에서 제거합니다. 브라우저 확장, 주소 복사, 스크린샷 등으로는 노출될 수 있습니다.
- 개별 참가자의 세션 토큰·공유 세대 토큰은 페이지 메모리에만 보관하며 링크, 영구 저장소, 위치 요청 URL에 넣지 않습니다.
- 서버는 마지막 위치 한 개만 RAM에 유지합니다. 30초가 지나면 오래된 것으로 표시하고 90초 이상이면 조회에서 제외하고 삭제합니다. 정기 메모리 정리 작업은 실행 환경 지연의 영향을 받을 수 있습니다.
- 중지를 누르면 새 전송을 즉시 멈추고 마지막 위치 삭제를 요청합니다. 실패하면 삭제 여부가 확인되지 않았다고 표시하며 90초 자동 숨김에 의존합니다. 화면 잠금·앱 전환·목적지 변경도 공유를 중지합니다.
- 방장은 방 전체를 종료할 수 있습니다. 개별 참여자는 나갈 수 있습니다. 방은 기본 6시간, 최대 24시간 이내 만료하며 서버 재시작 시 사라집니다.
- 종단간 암호화가 아닙니다. 신뢰하는 서버 운영자와 호스팅 업체가 데이터를 처리할 수 있습니다. 포함된 서버는 요청 로그를 만들지 않지만 실제 호스팅·프록시 로그는 운영자가 별도로 검토·설정해야 합니다.
- 이미 다른 사람이 본 정보나 캡처를 회수하지 못합니다. 동의하지 않은 사람을 추적하는 기능은 없습니다.

## 안전

ETA는 추정치이며 신호 대기, 경사, 통행 제한, 버스 지연·조기 출발을 반영하지 않습니다. 버스 시간은 직접 입력한 숫자의 카운트다운일 뿐 실시간 교통정보가 아닙니다. 목적지를 탑승할 정류장으로 설정했는지, 길과 탑승 방향이 맞는지 확인하세요. ETA를 맞추려고 무리하게 뛰거나 안전하지 않은 길을 이용하지 마세요.
