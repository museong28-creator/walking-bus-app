    어떻게 갈까요?

    버스 + 도보 / 연결 필요

    버스 노선/환승 경로 API가 아직 연결되지 않아 총 이동시간을 계산할 수 없어요. 정류장 위치만으로 버스 경로를 만들지 않아요.

    가로등 등록 정보 / 밝기 미확인

    실제 밝기 자료는 없어요. 선택적으로 지도에 등록된 가로등 수만 확인할 수 있어요. 가로등 수로 밝거나 안전한 길을 추천하지 않아요.

    속도 설정과 이용 안내

    실제 속도는 최근 GPS 측정값을 완만하게 반영해요. 정지하면 ETA도 멈추고, 위치가 부정확하면 표시를 보류해요.

    iPhone Safari: HTTPS에서 위치 권한을 허용해 주세요. 화면 잠금이나 앱 전환 시 걷기 측정이 일시 중지돼요. 다시 열어 시작 버튼을 눌러 주세요.

    공개 데이터: 장소 검색은 Kakao, 도보 경로는 FOSSGIS, 정류장 검색은 Overpass를 사용해요. 요청 전에 전송 내용을 안내해요. 무료 공용 서비스는 느리거나 중단될 수 있고 보행로가 누락될 수 있어요.

    신호 대기/경사/교통 상황은 반영하지 않아요. 실제 표지판과 안전을 우선하고, 길을 건널 때는 화면을 보지 마세요.

      몇분 걸음 계정

      Google 로그인 후 대구대(정문1) 894번 실제 도착정보를 조회할 수 있어요. 현재는 등록된 초기 사용자만 서버를 이용할 수 있어요.

      로그인 준비를 누르면 Google/Firebase에 연결돼요. 로그인하면 이름/이메일/계정 ID가 이 앱의 Firebase 인증에 제공돼요. 위치는 로그인 과정에서 보내지 않아요. 로그인은 이 브라우저 탭 세션에만 유지돼요.

      직원1 채팅에 이 ID만 보내 주세요. 비밀번호/인증 토큰은 필요하지 않아요.

      서버 보호 연결 확인을 누르면 인증 토큰과 계정 ID를 이 앱의 Render 서버로 보내고 Firebase 사용량 한도에 1회를 기록해요. 위치나 버스 정보는 요청하지 않아요.

      로그인 없이도 기존 지도와 보행 측정을 이용할 수 있어요.
