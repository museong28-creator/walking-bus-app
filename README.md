# 내 걸음 · MY PACE v0.2

지도에서 목적지를 고르고, 실제 보행 속도로 도착 예상 시간을 계산하는 **개인용 웹 프로토타입**입니다. iPhone Safari를 고려해 만들었습니다. 이 저장소는 공개 소스이며 정적 웹사이트를 GitHub Pages에서 제공합니다.

## 현재 구현된 것

- 온라인 지도에서 임의의 목적지 선택, 장소 검색, 위도·경도 직접 입력
- 지도에서 출발지 지정 또는 브라우저 GPS로 현재 위치 측정
- **보행 전용** FOSSGIS/OSRM 공개 서버에서 실제 도보 경로 요청
- GPS 속도 또는 시간에 따른 위치 변화로 최근 보행 속도 추정
- 최근 속도와 경로상 남은 거리에 따른 ETA 갱신
- GPS 오차·순간이동·차량 속도·오래된 위치를 감지하고 ETA 보류
- 정지 시 ETA 보류, 경로 이탈 시 수동 경로 재탐색 안내
- OpenStreetMap에 등록된 주변 700m 버스 정류장 검색 및 목적지 지정
- **직접 입력한** 버스 도착 시간과 도보 ETA 비교 (1분 여유 포함)
- 별도 위치 권한/네트워크 없이 사용할 수 있는 명확히 표시된 가상 체험
- 목표 약속/버스 시각과 도착 여유 설정, 필요한 평균 보행 속도·분/km 계산
- 편한 속도 상한을 넘는 경우 무리한 속도를 제시하지 않고 시간 조정 안내
- 친구 초대 약속방, 동의한 참가자의 실제 위치·ETA·갱신 시각 표시
- 공유 시작/중지/나가기, 30초 오래됨 표시·90초 위치 숨김, 호스트 방 종료
- 선택적으로 실행하는 **별도 Node 공유 서버**와 실제 두 독립 클라이언트 통신 테스트
- HTTPS 대응, 상대 경로, 정적 빌드, 기본 PWA 셸
- 공개 정적 사이트: GitHub Pages의 `gh-pages` 브랜치에서 제공 (공유 서버는 미배포)

## 아직 구현되지 않은 것

- **전국 실시간 버스 도착정보:** 연동하지 않았습니다. 공공데이터/지역별 API와 별도 서버가 필요합니다. 정류장 검색은 실시간 운행 정보를 의미하지 않습니다.
- iPhone에서 화면 잠금·앱 전환 중 계속되는 백그라운드 GPS: 웹에서는 보장할 수 없습니다. 숨겨지면 측정을 중지하고 재시작을 요구합니다.
- 신호 대기·경사·출입구·지하 통로·도로 공사 반영, 안전한 경로 보장
- 모든 국가/지역/목적지의 보행로 데이터 완전성, 공용 서비스의 가용성 보장
- 영구 친구 계정/본인 인증·친구 목록 저장: 없습니다. 이번 약속방에 링크로 참여하는 방식입니다.
- 공유 서버의 실제 HTTPS 배포: 하지 않았습니다. GitHub Pages에 정적 파일만 올려서는 기기 간 공유가 작동하지 않습니다.
- 이동 이력·장기 저장·음성 안내: 없습니다. 공유를 켠 경우 서버 RAM에 **마지막 위치 하나**를 임시 보관합니다.

이 프로토타입은 전국 실시간 대중교통 서비스나 완성된 내비게이션이 아닙니다. 경로가 없으면 직선거리는 표시하되 **도보 ETA를 만들지 않습니다.**

## v0.2: 약속 시간과 친구 위치

“약속 시간에 맞춰”에서 날짜·시간·도착 여유·내 편한 속도 상한을 정합니다. 실제 도보 경로를 확보한 뒤 현재 속도와 필요한 평균 속도를 비교합니다. 설정한 속도가 안전을 보장하는 것은 아닙니다. 신호·경사·교통은 반영하지 않으며, 빠듯하면 시간 조정이나 다음 버스를 권합니다.

친구 위치는 가상 시뮬레이션으로 대체하지 않습니다. 공유 서버를 구성하지 않은 상태에서는 **서버 설정 필요**라고 표시하며 아무도 추적하지 않습니다. 실제 공유에는 아래 추가 설정이 필요합니다.

1. 포함된 Node API를 신뢰할 수 있는 HTTPS 호스트에 배포합니다. [공유 서버 실행·배포 안내](docs/SHARING_SERVER.md)를 따르세요. 서비스 계정·호스팅·도메인·TLS는 아직 생성하지 않았습니다.
2. API의 `ALLOWED_ORIGINS`에 실제 GitHub Pages Origin만 허용하고, 앱의 공유 서버 입력란에 해당 API 주소를 입력합니다.
3. 실제 목적지와 약속 시간을 정하고 표시 이름을 입력한 뒤 전송 항목을 확인하여 방을 만듭니다.
4. 초대 링크를 복사해 신뢰하는 친구에게 직접 보냅니다. 친구는 링크를 열고 자신의 이름으로 참여합니다. 이름은 검증된 계정이 아니며 링크를 가진 사람이 추가로 참여할 수 있습니다.
5. **각자** “내 실시간 위치 공유 시작”을 누르고 안내·위치 권한에 동의해야 자신의 좌표가 전송됩니다. 참여만으로는 공유하지 않습니다.
6. 화면을 켜 둔 동안 약 5초 간격으로 새 위치를 보내며, 친구의 공유 위치를 지도에 표시합니다. 각자 실제 경로와 측정 속도가 있을 때만 ETA를 보냅니다.
7. 공유 중지 버튼, GPS 중지, 목적지 변경, 화면 잠금/앱 전환으로 새 위치 전송을 멈추고 서버 삭제를 요청합니다. 통신이 끊기면 마지막 위치는 최대 90초 후 숨깁니다.

앱은 마지막 좌표만 공유하며 이동 경로를 저장하지 않습니다. 종단간 암호화는 아니며 신뢰하는 서버 운영자가 처리 데이터를 볼 수 있습니다. 초대 링크를 전달받은 사람도 방에 들어올 수 있고, 이미 본 정보나 캡처는 회수할 수 없습니다. 방은 기본 6시간 후 만료되며 서버 재시작 시 사라집니다.

개인 참여 토큰은 현재 페이지에만 있어 새로고침하면 해당 세션에 다시 접근할 수 없습니다. 같은 초대로 다시 참가할 수 있으나 새 참가자가 되며 방장 권한은 복구되지 않습니다. 필요 없는 방은 새로고침/종료 전에 “모두의 약속방 종료”로 닫아 주세요. 영구 계정·친구 목록 대신 일회성 약속방을 사용하는 초기 버전의 한계입니다.

## 가장 빠른 실행

Node.js 22 이상을 권장합니다. 런타임 패키지 설치는 필요하지 않습니다. Leaflet 1.9.4는 라이선스와 함께 포함되어 있습니다.

```sh
npm run dev
# http://127.0.0.1:3000 열기
```

file://로 열면 JavaScript 모듈과 위치 권한이 작동하지 않을 수 있습니다. iPhone에서 실제 위치를 테스트하려면 HTTPS로 배포하세요. PC의 사설 IP에 http로 접속하는 것은 보안 컨텍스트가 아니므로 GPS가 막힐 수 있습니다.

## 공개 사이트와 배포 범위

사이트: https://museong28-creator.github.io/walking-bus-app/

`museong28-creator/walking-bus-app`만 공개 저장소로 전환했습니다. GitHub Pages는 `gh-pages` 브랜치의 정적 앱만 제공합니다. `main`의 소스 변경은 자동으로 게시되지 않으며, 검증 후 `npm run build`의 `dist/` 내용을 `gh-pages`에 반영해야 합니다.

공유 서버·실시간 버스 API·사용자 계정은 배포하지 않았습니다. 친구 위치 기능은 별도의 신뢰할 수 있는 HTTPS 서버를 직접 구성해야 동작하며, 사이트만 열어서는 위치를 공유하거나 다른 사람을 추적하지 않습니다. 소스가 공개되어도 방문자의 GPS 정보가 저장소에 올라가지는 않습니다.

## iPhone 테스트 순서

1. HTTPS 페이지를 열고 “데이터 없이 체험하기”로 화면 동작을 먼저 확인합니다.
2. 체험을 종료하고 “온라인 지도 켜기”를 누릅니다. OpenStreetMap에 보이는 지역과 IP가 전달됩니다.
3. 목적지를 검색하거나 지도에서 선택합니다. 검색은 입력한 검색어만 Nominatim에 보냅니다.
4. “내 위치로 걷기 시작”을 누르고 Safari 위치 권한을 허용합니다. 안전한 곳에서 20~30초 정도 걸어 봅니다.
5. “도보 경로 찾기”를 누르고 안내를 확인합니다. 출발지와 목적지 좌표가 FOSSGIS 서버로 전송됩니다. 걷는 동안 자동으로 재전송하지 않습니다.
6. 속도·남은 거리·ETA가 바뀌는지 확인합니다. 걸음을 멈추면 잠시 뒤 정지로 표시합니다.
7. 화면을 잠갔다 돌아오면 측정이 중지되었는지 확인하고 다시 시작합니다.
8. 정류장을 목적지로 고르고, 다른 버스 앱에서 확인한 남은 시간을 입력해 비교합니다.

기본 속도는 측정하지 않을 때만 사용합니다. GPS 측정 중에는 충분한 신뢰도의 속도가 나오기 전까지 ETA를 보류합니다. GPS 장치가 속도를 제공하지 않으면 위치 변화로 추정하므로 느린 보행·도심·실내에서 오차가 큽니다.

## 검증

```sh
npm run check
npm run build
```

테스트 결과와 한계는 `docs/TESTING.md`에 기록합니다. 실제 iPhone에서 걷는 현장 테스트는 별도입니다. 시뮬레이션이나 데스크톱 테스트가 iPhone 센서 검증을 대신하지 않습니다.

## 외부 서비스와 개인정보

처음 페이지를 열 때 외부 지도·경로·장소·정류장 요청을 보내지 않습니다. 지도는 명시적으로 켠 후 요청하고, 검색·경로·정류장 요청은 각각 동의 창을 거칩니다. 위치 이력이나 API 키를 저장하지 않습니다. 브라우저에는 정적 앱 파일과 정상적인 HTTP 캐시가 남을 수 있습니다. 세부 사항은 [개인정보 안내](docs/PRIVACY.md)를 확인하세요.

약속방은 별도 동의 후 이름·목적지·시간을 서버와 참가자에게 공유합니다. 정확한 현재 좌표·오차·시각·속도·ETA는 다시 “공유 시작”에 동의한 뒤에만 보냅니다. 초대 토큰은 URL fragment에, 개인 세션 토큰은 현재 페이지 메모리에만 두며 영구 저장하지 않습니다. 입력한 서버 주소 외에 자동으로 연결하는 기본 공유 서버는 없습니다.

공용 서버는 개인용 시험을 위한 것입니다. 사용량이 늘면 사용 정책을 재확인하고 자체 서버 또는 적절한 계약 서비스로 전환해야 합니다. Nominatim 검색은 타이핑 중 자동 요청하지 않으며, 1.1초 간격 제한과 세션 캐시를 적용합니다. 지도 타일을 미리 내려받거나 오프라인 저장하지 않습니다.

## 구조

```text
index.html          한국어 접근성 UI
styles.css          모바일/데스크톱 반응형 스타일
src/core.js         거리, 경로 투영, 속도 필터, ETA, 버스 비교
src/services.js     외부 읽기 전용 서비스 어댑터
src/app.js          동의, GPS, 지도, 상태 처리
src/meeting.js      목표 시간·편한 속도·위치 신선도 계산
src/sharing.js      동의 뒤 사용하는 공유 API 클라이언트
src/meetup-ui.js    약속·초대·참가자 지도 UI
server/            선택적으로 배포할 별도 Node 공유 API
sw.js               위치가 없는 정적 셸만 캐시
scripts/            의존성 없는 로컬 서버와 정적 빌드
tests/              자동 테스트와 모바일 레이아웃 QA 페이지
docs/               개인정보, 테스트, 실시간 버스 확장 설계
```

Leaflet 저작권 및 BSD-2-Clause 라이선스는 `assets/vendor/leaflet.LICENSE`에 있습니다. 지도 데이터는 OpenStreetMap 기여자에게 저작권이 있으며 해당 데이터 라이선스·서비스 정책이 적용됩니다.
